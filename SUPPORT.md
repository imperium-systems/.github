# Support

## Questions and help

Ask on [GitHub Discussions](https://github.com/orgs/imperium-systems/discussions):

- **Q&A**: how to use a system, integration problems
- **Ideas**: suggestions for new systems or features
- **Show and tell**: projects built with Imperium

Search existing discussions before opening a new one.

## Bugs

Open an issue in the repository of the affected implementation, for example [`roblox`](https://github.com/imperium-systems/roblox/issues). Use the bug report template.

## Licensing and purchases

## Security

Never report a vulnerability publicly. Follow the [security policy](SECURITY.md).
